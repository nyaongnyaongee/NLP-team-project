# 개발용 확인 화면

학부모 · 교사를 한 화면에 나란히 놓고, 보낸 메시지가 저장돼 다른 계정에서 보이는지 확인하는 임시 화면.
서비스 화면(`frontend/`)이 아니다. 프론트가 나오면 필요 없어진다.

```
cd backend
py dev\dev.py          # Windows      (Mac 은 python3 dev/dev.py)
```

**정제(Claude API 호출)는 기본이 꺼짐**이다. 화면 위쪽 스위치로 켜고 끈다 (처음부터 켜려면 `dev.py --refine`). 꺼져 있을 때 보낸 메시지는 「정제하지 못했습니다」로 남고, 스위치를 켠 뒤 교사 칸의 「다시 정제」를 누르면 정제된다.

처음이면 루트 `README.md` 의 「실행」 절대로 PostgreSQL · `.venv` · `.env` 를 먼저 준비한다.
DB · 테이블 · 테스트 계정은 `dev.py` 가 알아서 만들고, PostgreSQL · 백엔드(8000) · 이 화면(5173) · React 화면(5174, node 가 있을 때) 을 켠 뒤 브라우저(React 화면)를 연다. React 없이 켜려면 `--no-react`.
끄기는 `Ctrl+C` (Mac 에서 `dev.py` 가 PostgreSQL 을 켰다면 같이 꺼진다). 열면 학부모 · 교사 칸이 이미 로그인돼 있다.

왼쪽(학부모)에서 보내면 오른쪽(교사)에 먼저 「정제 중…」이 뜬다. AI가 정제가 필요하다고 판단하면 정제문 · 분석 칩이 나오고, 명시적으로 통과시키면 원문이 그대로 나온다. 처리 전이나 정제 실패 시에는 교사에게 원문을 보여 주지 않으며, 실패 시 사유와 「다시 정제」가 나온다. 판정값이 없는 기존 AI 결과는 정제문으로 표시한다. 답장 초안은 교사가 「메모로 초안 쓰기」를 눌렀을 때만 만들고, 수정해 보낸 최종 답장만 메시지로 저장한다.
학부모 칸에는 자기가 쓴 글만 보인다(정제문 · 분석은 안 보임). 정제는 `backend/.env` 의 `ANTHROPIC_API_KEY` 로 진짜 Claude 를 부른다(건당 약 $0.006).
