# 학부모 민원 정제 합성 데이터셋

한국 초등학교 학부모가 교사에게 보내는 민원 메시지에서 욕설, 인신공격, 비꼼, 조롱, 과도한 요구, 압박성 표현, 감정적 과장 등을 식별하고, 핵심 사실과 요청은 유지하면서 자연스러운 존댓말로 정제하는 한국어 NLP 데이터셋입니다.

## 중요 안내

- 이 데이터셋의 모든 메시지는 연구와 모델 평가를 위해 작성한 **합성 데이터**입니다.
- 실제 학부모, 학생, 교사 또는 학교의 민원과 개인정보를 수집하거나 전재한 데이터가 아닙니다.
- 원본 메시지에는 연구 목적상 마스킹하지 않은 한국어 욕설과 공격적 표현이 포함되어 있습니다.
- 합성 데이터이므로 실제 학교 현장의 모든 문체와 상황을 대표하지 않으며, 모델 결과를 실제 민원 처리에 사용할 때에는 사람의 검토가 필요합니다.

## 파일 구성

```text
dataset/
├── README.md
├── full_1000.jsonl
├── full_1000.csv
└── splits/
    ├── train.jsonl
    ├── validation.jsonl
    └── test.jsonl
```

| 파일 | 데이터 수 | 용도 |
|---|---:|---|
| `full_1000.jsonl` | 1,000 | 전체 데이터 |
| `full_1000.csv` | 1,000 | 전체 데이터의 CSV 변환본 |
| `splits/train.jsonl` | 800 | 학습 데이터 |
| `splits/validation.jsonl` | 100 | 검증 데이터 |
| `splits/test.jsonl` | 100 | 최종 평가 데이터 |

JSONL 파일은 한 줄에 하나의 JSON 객체를 저장합니다. 텍스트 인코딩은 UTF-8이며, CSV는 스프레드시트 호환성을 위해 UTF-8 BOM을 사용합니다.

## 주요 필드

| 필드 | 설명 |
|---|---|
| `id` | `000001`부터 시작하는 고유 식별자 |
| `input` | 공격적이거나 과도한 표현이 포함될 수 있는 합성 학부모 원본 메시지 |
| `output` | 사실과 요청을 보존하면서 부적절한 표현을 정제한 메시지 |
| `type` | 학생 간 갈등, 학업·성적 등 민원 유형 |
| `tone` | 중립, 걱정, 불만, 분노, 격앙 등의 감정 수준 |
| `issue_tags` | 메시지에 포함된 문제 표현 및 상황 라벨 목록 |
| `primary_issue` | 데이터 분포를 구성할 때 사용한 대표 문제 표현 유형 |
| `edit_level` | 정제 강도(`none`, `light`, `medium`, `heavy`) |
| `request` | 메시지의 핵심 요청 |
| `scenario_id` | 합성 사건 시나리오 식별자 |
| `request_modified` | 정제 과정에서 요청의 의미가 변경되었는지 여부 |

`length`, `style`, `provenance`, `scenario_family_id`는 생성 단계에 따라 일부 레코드에만 존재하는 보조 메타데이터입니다.

## 데이터 분포

전체 1,000개는 12개 민원 유형에 83~84개씩 배분했습니다. 대표 문제 표현 분포는 다음과 같습니다.

| 대표 문제 표현 | 개수 |
|---|---:|
| 욕설·인신공격 | 180 |
| 비꼼·조롱 | 150 |
| 과도한 요구 | 180 |
| 압박·협박성 표현 | 120 |
| 감정적 과장 | 120 |
| 복합 표현 | 150 |
| 정제 불필요 | 100 |

## 생성 및 정제 방식

사건 시나리오를 먼저 구성한 뒤 원본 메시지와 정제문을 쌍으로 작성했습니다. 기존 Pilot 30개와 첫 번째 검토 배치 50개를 보존하고, Codex가 작성한 결정론적 로컬 합성기를 이용해 920개를 추가했습니다. 최종 데이터 생성에는 외부 OpenAI API, 외부 유료 LLM API 또는 API 키를 사용하지 않았습니다.

정제문은 다음 원칙을 따릅니다.

- 욕설, 모욕, 인신공격 및 불필요한 비꼼을 제거합니다.
- 원문의 핵심 사실, 불만 및 요청을 유지합니다.
- 확인되지 않은 내용은 확정적인 사실로 바꾸지 않습니다.
- 과도하거나 부당한 요청도 임의로 삭제하거나 다른 요청으로 대체하지 않고 정중하게 표현합니다.
- 긴급한 안전 문제는 정제 후에도 긴급성을 유지합니다.

## 검증 및 분할

JSON 구조, ID 연속성, 필수 필드, 중복 원문, 정제문 공격 표현 잔존 여부와 분할 무결성을 검사했습니다. 최종 파일은 정확히 1,000개이며 ID는 `000001`부터 `001000`까지입니다. Train/Validation/Test는 서로 겹치지 않고 합치면 전체 1,000개와 일치합니다. 동일한 시나리오 계열이 서로 다른 분할에 들어가지 않도록 그룹 단위로 분할했습니다.

이 데이터셋에는 의도적으로 강한 욕설과 위협적 표현이 포함되어 있습니다. 콘텐츠 필터링, 모델 안전성 평가 및 사람 검토 절차를 함께 적용하는 것을 권장합니다. 데이터 사용 조건은 이 저장소의 라이선스 및 프로젝트 정책을 확인해 주세요.
