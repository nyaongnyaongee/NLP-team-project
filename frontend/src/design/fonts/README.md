# 폰트 넣는 곳

`sky-tokens.css` 는 아래 두 파일을 이 폴더(`src/design/fonts/`)에서 찾습니다. 지금은 파일이 없어서 **시스템 폰트로 동작**합니다 (화면은 정상입니다. 개발 서버 콘솔에 폰트 404 가 보일 수 있습니다).

| 파일 이름 | 폰트 | 용도 |
| --- | --- | --- |
| `PretendardVariable.woff2` | Pretendard (가변 폰트) | 본문 |
| `NanumSquareRoundB.woff` | 나눔스퀘어라운드 Bold | 제목, 로고 글자 |

## 넣는 방법

1. 팀에서 폰트 원본과 **라이선스를 확인**합니다 (명세 10장: 확인할 수 없었던 것).
2. 위 파일 이름 그대로 이 폴더에 복사합니다. `sky-tokens.css` 는 고치지 않습니다.
3. 개발 서버를 다시 켭니다 (`npm run dev`). 빌드(`npm run build`) 때 폰트가 결과물에 함께 들어갑니다.

파일 이름을 바꾸고 싶으면 `sky-tokens.css` 가 아니라 이 폴더에서 이름만 맞추세요.
